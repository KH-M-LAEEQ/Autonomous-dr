# Results

Every number that appears in the thesis is generated into this directory by
`make results`, from raw data, by one script (Week 31 requirement).

Commit bad results too. A detector that lost is a row in the comparison table and
a paragraph in the discussion. A detector that lost and was deleted is the thing
that gets found in the viva.

Naming: `wNN-topic.md` for narrative, `wNN-topic.csv` for tables, `wNN-topic.png`
for figures.
