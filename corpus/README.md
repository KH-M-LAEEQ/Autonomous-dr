# Corpus (Week 15)

Target: 150+ documents — AWS Post-Event Summaries, Azure PIRs, GCP incident
reports, Cloudflare and GitHub post-mortems, provider reliability docs, plus your
own runbooks.

**Documents themselves are gitignored** (licensing varies and the repo stays
small). What IS committed: `sources.yaml` listing every URL, and the fetch script
that rebuilds the corpus from it. Anyone should be able to reconstruct the corpus
from this repo alone.
